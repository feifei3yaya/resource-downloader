# 网站资源下载器

自动访问网站，提取并批量下载所有图片和视频资源。

## 触发条件

当用户满足以下任一场景时，必须立即激活本 Skill：

1. 用户提供了一个网站URL，并要求下载该网站的图片或视频
2. 用户提到"下载网站图片"、"网站视频下载"、"抓取网站资源"等关键词
3. 用户展示了一个网站，并希望保存其中的图片或视频
4. 用户需要备份某个网站的媒体资源

## 工作流程

### 第一步：确认网站URL

向用户确认需要下载资源的网站URL，确保URL格式正确且可访问。

如果用户没有直接提供URL，则主动询问：
```
请提供需要下载资源的网站URL，我将帮你提取并下载所有图片和视频。
```

### 第二步：访问网站并获取网络请求

使用 `integrated_browser` 工具访问目标网站：

1. **导航到网站**：使用 `browser_navigate` 工具访问用户提供的URL
2. **获取网络请求**：使用 `browser_network_requests` 工具获取所有网络请求
3. **等待页面加载**：确保页面完全加载后再获取网络请求

### 第三步：提取资源URL

从网络请求中筛选和提取资源URL：

**图片资源筛选规则**：
- 文件扩展名：`.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`, `.svg`, `.bmp`, `.ico`
- Content-Type 包含：`image/`
- URL路径包含：`/images/`, `/assets/`, `/static/`, `/media/`, `/img/`

**视频资源筛选规则**：
- 文件扩展名：`.mp4`, `.webm`, `.avi`, `.mov`, `.mkv`, `.flv`
- Content-Type 包含：`video/`
- URL路径包含：`/videos/`, `/media/`, `/assets/video/`

**去重处理**：
- 检查URL是否重复
- 跳过看起来相同的资源（如不同尺寸的缩略图）
- 保留完整质量的资源版本

### 第四步：创建下载脚本

根据提取到的资源URL，生成PowerShell下载脚本：

**脚本功能**：
1. 创建输出目录结构
   - `website_images/` - 存放所有图片
   - `website_videos/` - 存放所有视频
2. 按资源类型分类下载
3. 显示下载进度
4. 记录成功和失败的下载
5. 生成下载报告

### 第五步：执行下载并验证

1. **运行下载脚本**：执行生成的PowerShell脚本
2. **监控进度**：实时显示下载进度和状态
3. **验证下载**：检查下载的文件是否完整
4. **处理错误**：自动重试失败的下载（最多3次）

### 第六步：生成下载报告

下载完成后，输出详细的下载报告：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  📥 网站资源下载报告
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🌐 目标网站：{website_url}

📊 下载统计
  🖼️  图片资源：{image_count} 个
  🎬  视频资源：{video_count} 个
  ✅  成功下载：{success_count} 个
  ❌  下载失败：{fail_count} 个

📂 保存位置
  图片目录：{image_path}
  视频目录：{video_path}

✅ 下载完成！
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 第七步：后续处理选项

提供以下后续处理选项：
1. **打开下载目录** - 在文件管理器中打开下载目录
2. **重新下载失败资源** - 只重新下载失败的资源
3. **生成资源列表** - 生成包含所有下载资源URL的文本文件
4. **压缩打包** - 将所有下载的资源压缩成一个ZIP文件

## 高级功能

### 1. 智能过滤

- 自动过滤掉广告图片、跟踪像素等不需要的资源
- 按文件大小过滤，跳过过小或过大的资源
- 支持用户自定义过滤规则

### 2. 资源分类

根据URL路径自动分类资源：
- `website_images/thumbnails/` - 缩略图
- `website_images/logos/` - Logo和图标
- `website_images/backgrounds/` - 背景图
- `website_videos/trailers/` - 预告片
- `website_videos/demos/` - 演示视频

### 3. 断点续传

支持下载中断后的续传功能：
- 保存下载进度到临时文件
- 重新运行时检查已下载的文件
- 只下载未完成的部分

### 4. 元数据保存

为下载的资源生成元数据文件：
- 资源原始URL
- 文件大小
- 下载时间
- 文件类型
- 图片尺寸（仅图片）

## 注意事项

1. **合法性**：请确保下载网站资源符合相关法律法规和网站使用条款
2. **带宽**：大量下载可能消耗较多带宽，请在合适的网络环境下使用
3. **速率限制**：避免短时间内大量请求，建议添加适当延迟
4. **存储空间**：确保有足够的磁盘空间存储下载的资源
5. **动态内容**：对于动态加载的内容，可能需要滚动或交互以触发加载
6. **认证网站**：需要登录的网站，请先在浏览器中完成登录再使用本skill

## 技术细节

### 支持的图片格式
- PNG, JPG/JPEG, GIF, WebP, SVG, BMP, ICO

### 支持的视频格式
- MP4, WebM, AVI, MOV, MKV, FLV

### 默认下载设置
- 并发下载数：3
- 重试次数：3
- 超时时间：30秒
- 用户代理：Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36
